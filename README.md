# 🏋️ IRONPEAK GYM — HexSoftwares Internship Project

A modern, responsive **single-page gym website** built using **HTML5, CSS3, and Vanilla JavaScript** for the HexSoftwares Internship (Project 2).

---

## 🚀 Live Demo
👉 https://fazal305.github.io/HexSoftwares_GymWebsite/

---

## 📌 Project Overview

IRONPEAK GYM is a fully responsive fitness landing page designed to showcase:

- Gym facilities
- Services and programs
- Membership pricing plans
- Professional trainers
- Customer testimonials
- Contact form with validation

The project focuses on clean UI design, smooth animations, and interactive JavaScript functionality without using any frameworks.

---

## ✨ Features

- 🧭 Fixed navigation bar with smooth scrolling
- 📊 Animated counter stats section
- 🏋️ Facilities showcase with images
- 🎯 Interactive services tabs (Vanilla JS)
- 💳 Membership pricing toggle (Monthly / Yearly)
- 👨‍🏫 Trainer profiles with images
- ⭐ Testimonials auto-slider (carousel)
- 📩 Contact form with validation
- ⬆️ Back-to-top button
- 📱 Fully responsive design (mobile-first)
- ✨ Scroll reveal animations using IntersectionObserver

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Variables)
- JavaScript (Vanilla JS)
- IntersectionObserver API
- setInterval / DOM Events
